# AI AI Captain features

- **Session keys.** Each AI session has one key. The key shows a state: STARTING, WORKING, WAITING, DONE, FAILED, or UNKNOWN. Each state has a symbol, a label, and a color.
- **Attention.** A WAITING key pulses when the session needs you. A new DONE key flashes.
- **Info keys.** An info key goes below a session key. It shows the model, the tokens in use, and a context bar. A padlock shows the freedom of the session. Green chevrons show that the session never asks you.
- **Supported tools.** Codex, Claude Code, Junie, and Copilot sessions are found automatically. Claude desktop chats and the ChatGPT app also show. Other tools can report through a command or the local API.
- **Go to the work.** Press a session key to bring its window to the front.
- **Deck keys.** Use the **Toggle Info Keys**, **Cycle Theme**, and **Cycle Brightness** keys to change settings. The INFO key opens the dashboard.
- **Dashboard and virtual deck.** Use the browser to see all sessions and to change settings. Use the virtual deck when you have no Stream Deck.
- **Themes.** Choose from five color themes.
- **Systems.** The plugin runs on macOS and Windows. The hub and the dashboard also run on Linux.
- **Privacy.** The hub accepts connections from your own computer only. It does not keep prompts or answers.
